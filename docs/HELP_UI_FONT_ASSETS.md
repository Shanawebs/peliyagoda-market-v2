# Help Popup font assets

Builds bundle **Noto Sans Sinhala** for consistent Sinhala script rendering.
Run `bash scripts/prepare_sinhala_font.sh` once before building locally.
The GitHub Actions workflow performs this automatically and verifies both
font and SIL Open Font License hashes against the upstream Google Fonts files.

Google Sans is not bundled because the project has no redistribution grant.
The rest of the UI uses the Android sans-serif family.

Cloud DEV 2.35 has a separate application ID to preserve Cloud DEV 2.34
data with independently signed debug builds. Back up the previous version,
restore it into 2.35 using the Owner PIN, and verify records before uninstalling
any old versions. JSON backups do not include invoice images.

Future releases should use a consistently signed keystore to allow normal
in-place updates while retaining local records and the restore PIN.
